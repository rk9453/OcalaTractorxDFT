# Ocala Tractor · Proposal by DFT

Interactive proposal prepared by DFT for Ocala Tractor (October 2026).

Open `index.html` in a browser. It is a single self-contained page with six clickable demos, switched by the top nav:

- **Proposal** – findings on ocalatractor.com, the buyer journey, and the plan
- **Website** – the current site with live chat, store picker and online booking
- **AI receptionist** – after-hours call/text demo that routes leads to the right store
- **Sales follow-up** – Pipedrive pipeline tour across Ocala, Palatka and Eustis
- **90-day results** – before/target dashboard
- **Past customers** – reactivation campaigns and calculator

The AI receptionist uses Claude when opened as a claude.ai artifact; anywhere else it falls back to scripted replies.
